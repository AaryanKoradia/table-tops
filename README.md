# Table Tops

A static restaurant landing page -- menu, dishes, about section -- built as front-end coursework, with scroll-reveal and tilt animations.

## View it

Open `index.html` directly in a browser -- no build step or server needed.

## Tech

Plain HTML, CSS, and vanilla JavaScript, using [ScrollReveal](https://scrollrevealjs.org/) (`scrollreveal.min.js`) for scroll animations and [Vanilla Tilt](https://micku7zu.github.io/vanilla-tilt.js/) (`tilt.js`) for the tilt-on-hover effect.
